Zenith Help & Documentation

Keyboard shortcuts, search engine prefixes, extensions, and profile guide.

⚡ Navigation & Command Palette

Use Zenith's built-in overlays for fast keyboard-driven browsing without leaving your context.

Action Shortcut Description
Open Command Palette Ctrl + Shift + P Access quick commands, toggle dark mode, or run cleanups.
Spotlight Search Bar Ctrl + L / Ctrl + K / Alt + T Open the central URL and search engine overlay.
Ad Blocker Popup Ctrl + Shift + A View ad/tracker stats and switch protection modes.

🔍 Search Engine Prefixes

Type any prefix followed by your query in the Spotlight Search Bar to target specific search providers directly.

g <query>

Search using Google

d <query>

Search using DuckDuckGo

b <query>

Search using Brave Search

k <query>

Search using Kagi

gh <query>

Search repositories on GitHub

yt <query>

Search videos on YouTube

r <query>

Search threads on Reddit

🧩 Integrated Extensions

Zenith features built-in modular extensions customizable from Settings (Ctrl + ,).

YouTube Shorts Blocker

Redirects Shorts to normal watch pages and strips short shelf UI clutter.

Dark Reader Lite

Forces a high-contrast dark theme onto bright websites.

Distraction-Free Reader Mode

Strips web ads and navigation menus to focus purely on article content.

Cookie & Storage Cleaner

One-click instant wipe of HTTP cache, cookies, and session data for privacy.
